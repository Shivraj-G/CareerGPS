## 3. LIVE RECOMMENDATION
**Endpoint:** `POST /api/v1/recommendations/careers`

The recommendation service correctly gathers the live user's profile, skills, and stated career goal from PostgreSQL, builds the context payload, and sends it to the AI service via `POST /internal/v1/recommendations/careers`. The AI service mathematically scores the required skills against the user's profile and returns the recommendations, which the backend then persists to the `recommendations` table. 

**Live recommendation generated for User A (BCA):**
Recommendation ID: `d13af3ae-f5b1-415d-9d11-129c1b784412` (along with many others generated in testing today).
This is a live record generated dynamically and clearly distinguishable by its recent `created_at` timestamp compared to older seed data.
